# Agent guide

This file routes AI coding agents. It holds only what applies to every task; everything else lives in the document that owns it. Before acting, read what your task routes to below.

## Always

- Stay inside the [content boundaries](CONTRIBUTING.md#content-boundaries): nothing taken from a game, no DRM or unpacking work, no local paths or personal data.
- Install the hook with `python3 tools/check.py --install-hook`, never commit with `--no-verify`, and stage files by name.
- A change is on by default or not merged ([kinds of switches](docs/configuration.md)).
- Do not create documents. Update the document that describes what your code changed.
- Do not edit this file or CONTRIBUTING.md unless a maintainer asks.

## Your role

- You work for one person, who reviews what you produce and submits it under their name.
- Draft replies instead of posting to issues, pull requests or chats. Ask before pushing or opening a pull request.
- Propose trade-offs and let maintainers decide them. Report problems outside your task instead of fixing them.

## Routes

| Before you | Read |
|---|---|
| Look for where something lives or how parts connect | [ARCHITECTURE.md](ARCHITECTURE.md) |
| Build, run, test or package | [docs/building.md](docs/building.md) |
| Branch, commit, verify a change or open a pull request | [CONTRIBUTING.md](CONTRIBUTING.md) |
| Change behavior a rule covers, or write a test | [docs/spec/README.md](docs/spec/README.md), then the spec whose ID prefix the code cites |
| Change a crate's design | Its `//!` module docs and README, then the commit history |
| Add, remove or change an environment variable, option or feature | [docs/configuration.md](docs/configuration.md) |
| Debug a game or keep run output | [docs/investigation.md](docs/investigation.md) |
| Work on speed or power use | [Performance work](docs/investigation.md#performance-work) |
| Name something | [docs/glossary.md](docs/glossary.md) |
| Integrate, when your local configuration says you work for a maintainer | [docs/maintaining.md](docs/maintaining.md) |

## Language

Talk with your person in their language. Docs, code comments and commit messages are English; only `README.zh-CN.md` is not.
