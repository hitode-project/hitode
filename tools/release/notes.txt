**Mac**: not notarized. After the first warning, click "Open Anyway" in System Settings → Privacy & Security, or run `xattr -dr com.apple.quarantine /Applications/Hitode.app`.

**Mac**：未经公证。第一次被拦截后，在"系统设置 → 隐私与安全性"里点"仍要打开"，或在终端执行 `xattr -dr com.apple.quarantine /Applications/Hitode.app`。

**iOS / iPadOS**

- **TrollStore IPA**: If you already have TrollStore 2.0.12 or later, import this IPA into TrollStore. Tap Hitode in TrollStore’s app list and select **Open with JIT**.
- **Unsigned IPA**: Otherwise, use this IPA for sideloading with a development signature. Enable JIT before starting a game.

**iOS / iPadOS 安装说明**

- **TrollStore 包**：已安装 TrollStore 2.0.12 或更新版本时，选这个包。在 TrollStore 里导入 IPA，然后在应用列表中点按 Hitode，选择 **Open with JIT**。
- **无签名包**：其余用户选这个包，用开发签名侧载，进入游戏前先启用 JIT。
